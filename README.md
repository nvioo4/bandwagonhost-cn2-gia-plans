## CN2 GIA-E 是什么线路，和普通 CN2 差在哪

先说线路本身。中国电信对中国方向的国际线路大致分几档：最常见的是 163 骨干网（AS4134），便宜但晚高峰拥塞，丢包率高峰时可以到 30% 以上；然后是 CN2 GT（AS4809 的 Global Transit），贵一些，但搬瓦工官方在自己的线路说明页里直接承认，2019 年之后 GT 的拥塞问题和 163 差不多了；真正的天花板是 CN2 GIA（Global Internet Access），独立通道、负载低，成本也是天价——官方给出的参考是每兆比特月成本最高约 $120，1Gbps 带宽在某些市场一个月要花大约 10 万美元。

这就是为什么 CN2 GIA-E 系列的定价明显比普通 KVM 套餐贵：贵的主要不是 CPU 和内存，是回程线路。

具体到机房，这个系列默认可选的两个美国节点分工很清楚：

- **DC6（USCA_6）**：三网走 CN2 GIA，电信、联通、移动用户都吃到 GIA 级别的优化，是整个系列里最常被推荐的一个。
- **DC9（USCA_9）**：官方说明是搬瓦工网络容量和稳定性最好的节点，中国方向流量分给三条线路——电信 CN2 GIA（AS4809）、移动 CMIN2（AS58807）、联通精品网（AS10099）。洛杉矶两地机房合计 8 条 10Gbe 的 CN2 GIA/CTGNet 链路，并和 Google 等本地运营商直连。

日本方向的 JPOS_1 走软银线路，不少教程建议联通用户优先选它；荷兰的 EUNL_9 则走联通 AS9929。这几条线路各有侧重，后面讲迁移的时候会说怎么用。
